VRChat Avatars用のUnityプロジェクトを用意してください。

クイックスタート

インポートから指への取り付け、アップロードまで

必要な依存パッケージを先にインストールしてから進めてください。

1 UnityPackageをインポートする

本製品のUnityPackageを開きます。
Import画面で内容を確認し、Importを実行します。

確認ポイントインポートが完了し、Projectウィンドウから素材を探せます。

2 ProjectでPrefabを見つける

Projectウィンドウで、MirrorRingのPrefabを探します。
Prefabは、指輪と必要な設定をまとめた配置用のデータです。

確認ポイント指輪のPrefabを選べる状態になっています。

3 指ボーンの子に配置する

Hierarchyで導入先アバターのArmatureを開き、取り付けたい指のボーンを探します。
ProjectからMirrorRingのPrefabをドラッグし、指ボーンの子に配置します。

確認ポイントHierarchyで、MirrorRingが選んだ指ボーンの下に表示されています。

取り付け方式指ボーンへ直接配置します。
MA Bone Proxyによる自動追従設定は使用しません。

4 位置と向きと大きさを調整する

Hierarchyで配置したMirrorRingを選択します。
InspectorのTransformでPosition、Rotation、Scaleを調整します。
Sceneビューを見ながら、指に合う位置・向き・大きさに合わせてください。

確認ポイント指輪が取り付けたい指の位置に合っています。

数値について調整値は指やアバターの形状によって異なります。
共通の固定値はありません。

5 カメラの構成を保つ

Prefabには鏡面用メッシュとカメラが含まれています。
通常は付属カメラやRender Textureの参照を変更する必要はありません。
鏡面とカメラの相対的な配置を崩さないでください。

6 VRChatへアップロードして確認する

VRChat SDKからアバターをビルド・アップロードします。
Modular Avatarが正しく導入されていれば、付属メニューとFX Animatorが統合される構成です。
VRChatで指輪の表示とMirror Ringの切替を確認してください。

確認ポイントONでカメラ映像、OFFでCustom Imageに設定した画像が表示されます。

動作確認UnityのPlay Modeは補助的な確認に使えます。
VRChat固有の機能は、VRChat実機でも確認してください。

基本操作

Mirror Ringでカメラ映像と指定画像を切り替える

VRChatのラジアルメニューに追加されるMirror Ringを操作します。
初期状態はONです。

状態鏡面の表示付属カメラ
ONリアルタイムカメラ映像有効
OFFCustom Imageに設定した画像無効

確認ポイントメニューを切り替えると、鏡面の表示も切り替わります。

切替の設定について

鏡面の切替はアニメーションで制御されています。
通常はFX AnimatorやON/OFFアニメーションを変更する必要はありません。

画像を変えるときCustom Imageの設定方法はお好みの画像をご覧ください。
付属の切替を使う場合、Custom Image Blendの基本設定は0のままにします。

カメラ映像

Render Textureと映像の向き・色合いを確認する

RingMirrorマテリアルを開く

ProjectウィンドウでRingMirrorマテリアルを選択します。
InspectorのShaderがOKIYA/MirrorRingであることを確認します。

確認ポイントShaderにOKIYA/MirrorRingが表示されています。

カメラ映像の設定項目

項目役割基本設定
Camera Render Textureカメラ映像の参照先RingMirror_RT
Tiling X / Y映像の表示倍率1 / 1
Offset X / Y映像の表示位置0 / 0
Camera Tintカメラ映像の色合い白
Flip Horizontally左右反転1
Flip Vertically上下反転0

映像の向きを変える

Flip Horizontallyは、0で左右反転なし、1で左右反転ありになります。
通常の鏡らしい左右反転表示には、1を設定してください。

Flip Verticallyは、0で上下反転なし、1で上下反転ありになります。

通常の使い方Camera Render Textureは、付属のRingMirror_RTを使用してください。

お好みの画像

鏡がOFFのときに表示する画像を設定する

Custom Imageに画像を設定する

ProjectでRingMirrorマテリアルを選択します。
InspectorのCustom Imageに、表示したい画像を指定します。
必要に応じてTiling、Offset、Custom Image Tintを調整します。

確認ポイントVRChatでMirror RingをOFFにすると、指定した画像が表示されます。

項目役割基本設定
Custom ImageOFF時に表示する画像お好みの画像
Tiling X / Y画像の表示倍率1 / 1
Offset X / Y画像の表示位置0 / 0
Custom Image Blendカメラ映像と画像の表示割合0
Custom Image Tint画像の色合い白

Custom Image Blendの意味

値表示内容
0カメラ映像のみ
0.5カメラ映像と画像を半分ずつ合成
1指定画像のみ

付属の切替を使う場合Custom Image Blendはアニメーションによって変更されます。
マテリアル側の基本設定は0のまま使用してください。

透過PNGについて現行シェーダーは、Custom Imageのアルファ値による透過合成を行いません。
透明部分が自動的に透ける仕様ではありません。

鏡面の暗い部分に装飾的な明るさを加える

シルバー表現は、鏡面の暗い部分に装飾的な明るさを与える機能です。
ProjectでRingMirrorマテリアルを選び、Inspectorで調整します。

確認ポイントリアルタイムカメラの色をそのまま使う場合は、下記の3項目が0になっています。

項目役割基本設定
Silver Colorシルバー表現の色淡い青みのシルバー
Minimum Silver Brightnessシルバーの最低輝度0
Silver Gradient明るさのグラデーション0
Silver Sheen装飾的な光沢ライン0

カメラ映像の色をそのまま表示する

Minimum Silver Brightness、Silver Gradient、Silver Sheenをすべて0に設定します。
すべて0の場合、Silver Colorの色は実質的に表示されません。

MatCapの光沢

任意の光沢を追加するときの設定と注意点

MatCapは、鏡面に光沢や装飾的な反射を加える任意機能です。
標準構成では、MatCap Textureを「なし」のまま使用することをおすすめします。

MatCapを設定する

ProjectでRingMirrorマテリアルを選択します。
InspectorのMatCap Textureに画像を指定し、MatCap StrengthとMatCap Tintを調整します。

確認ポイントMatCapを使わない場合は、MatCap Textureが「なし」になっています。

項目役割基本設定
MatCap Texture光沢に使用する画像なし
Tiling X / Y現行シェーダーでは描画に反映されません1 / 1
Offset X / Y現行シェーダーでは描画に反映されません0 / 0
MatCap Strength光沢の強さ（0〜1）0
MatCap Tint光沢の色合い白

MatCap Strengthが0のとき、MatCapの加算表示は無効になります。
1のとき、指定したMatCapが最大強度で加算表示されます。

使わない場合はTextureを「なし」にする

付属のOFFアニメーションでは、MatCap Strengthが1に設定されます。
マテリアルの初期値を0にするだけでは、OFF中のMatCapは無効になりません。

ちらつく場合MatCapは、見る角度や指輪の向きに応じて変化します。
画像によっては強く光ったり、白くちらついたりする場合があります。
実機検証では、MatCap Textureを「なし」にして白いちらつきが解消しています。

困ったとき

よくある問題と確認方法

鏡面にカメラ映像が表示されない

次の順に確認してください。
1. RingMirrorのCamera Render Textureに付属のRingMirror_RTが設定されているか。
2. Mirror_Cameraの設定が変更されていないか。
3. ラジアルメニューのMirror RingがONになっているか。
4. FX Animatorが正しく導入されているか。

表示が左右逆または上下逆になっている

左右逆の場合は、Flip Horizontallyの値を切り替えます。
上下逆の場合は、Flip Verticallyの値を切り替えます。
どちらも0は反転なし、1は反転ありです。

鏡面が明るすぎる

Minimum Silver Brightness、Silver Gradient、Silver Sheenを0にします。
Camera Tintが白になっているかも確認してください。

OFF時の画像が白くちらつく

MatCap Textureが「なし」になっているか確認してください。
MatCapを設定していると、手や撮影カメラの動きで明るい反射が発生する場合があります。
詳しくはMatCapの光沢をご覧ください。

自分の顔が映らない

付属CameraのCulling Maskなどが変更されていないか確認します。
検証済み構成では、Playerを有効、PlayerLocalを無効、MirrorReflectionを有効にしています。
付属Cameraの初期設定をむやみに変更しないでください。

メニューが表示されない

Modular Avatarが導入されているか確認します。
PrefabのMA Menu Item、MA Menu Installer、MA Merge Animatorが正常に機能しているか確認してください。
